* Motivation

When a region is active, the cursor marks one end (the point) but the other end (the mark) has no visual indicator beyond the edge of the region highlight. =region-cursors= adds identical cursor-like overlays at both ends, making the selection clearly distinct.

* Features

+ Cursor overlays at both ends of the region (=box= and =bar= shapes).
+ Delayed cursor animations (blinking and pulsing) that start once the region is static.
+ Separate, theme-aware colors and faces for the point and mark cursors.
+ Clean whole-line selections: the end cursor sits at end of line.

Requires Emacs 27.1 or newer.

* Installation

** From MELPA

=region-cursors= is available on MELPA. With MELPA in your =package-archives=, install it with =M-x package-install RET region-cursors RET=, or use the declarative recipe:

#+begin_src emacs-lisp
  (use-package region-cursors
    :ensure t
    :config
    (region-cursors-mode 1))
#+end_src

** From Git

Using =use-package='s built-in =:vc= keyword (Emacs 30.1+):

#+begin_src emacs-lisp
  (use-package region-cursors
    :vc (:url "https://github.com/abidanBrito/region-cursors"
         :branch "main")
    :config
    (region-cursors-mode 1))
#+end_src

On Emacs 29, fetch the same recipe with =M-x package-vc-install RET https://github.com/abidanBrito/region-cursors RET=.

With [[https://github.com/progfolio/elpaca][elpaca]] (native =use-package= integration):

#+begin_src emacs-lisp
  (use-package region-cursors
    :ensure (:host github :repo "abidanBrito/region-cursors")
    :config
    (region-cursors-mode 1))
#+end_src

Or with [[https://github.com/radian-software/straight.el][straight.el]]:

#+begin_src emacs-lisp
  (use-package region-cursors
    :straight (region-cursors
               :type git :host github :repo "abidanBrito/region-cursors")
    :config
    (region-cursors-mode 1))
#+end_src

** From source

#+begin_src sh
  git clone https://github.com/abidanBrito/region-cursors.git ~/path/to/region-cursors
#+end_src

With =use-package=:

#+begin_src emacs-lisp
  (use-package region-cursors
    :load-path "~/path/to/region-cursors"
    :config
    (region-cursors-mode 1))
#+end_src

Or without =use-package=:

#+begin_src emacs-lisp
  (add-to-list 'load-path "~/path/to/region-cursors")

  (require 'region-cursors)
  (region-cursors-mode 1)
#+end_src

* Customization

All options live under =M-x customize-group RET region-cursors=.

| Variable                                | Default | Description                                               |
|-----------------------------------------+---------+-----------------------------------------------------------|
| =region-cursors-point-cursor-color=      | =nil=     | Point cursor color (overrides =region-cursors-point-face=). |
| =region-cursors-mark-cursor-color=       | =nil=     | Mark cursor color (overrides =region-cursors-mark-face=).   |
| =region-cursors-cursor-shape=            | =box=     | =box= or =bar=.                                             |
| =region-cursors-bar-width=               | =2=       | Bar width in pixels (=bar= shape only).                     |
| =region-cursors-animation=               | =pulse=   | =none=, =blink=, or =pulse=.                                  |
| =region-cursors-animation-interval=      | =0.75=    | Seconds between animation frames.                         |
| =region-cursors-animation-delay=         | =0.75=    | Delay before animation starts once the region is static.  |
| =region-cursors-pulse-steps=             | =10=      | Number of steps in a pulse animation cycle.               |
| =region-cursors-reset-animation-on-scroll= | =t=     | Reset animations when scrolling.                          |
| =region-cursors-scroll-settle-delay=     | =0.25=    | Seconds of scroll inactivity before restarting animation. |
| =region-cursors-anchor-trailing-newline= | =t=       | Draw the end cursor at end-of-line for whole-line selections. |
| =region-cursors-trim-line-selection=     | =t=       | Stop a triple-click line selection before the trailing newline. |
| =region-cursors-disable-hl-line-mode=    | =nil=     | Disable =hl-line-mode= while a region is active.            |
| =region-cursors-disabled-modes=          | ='()=     | Major modes where the mode should not activate.           |

For better theme integration you can also style the =region-cursors-point-face= and =region-cursors-mark-face= faces directly. Note that only their =:background= is used.

Example configuration:

#+begin_src emacs-lisp
  (use-package region-cursors
    :ensure t
    :custom
    (region-cursors-cursor-shape 'box)
    (region-cursors-animation 'pulse)
    (region-cursors-disable-hl-line-mode t)
    (region-cursors-disabled-modes '(org-mode))
    :config
    (region-cursors-mode 1))
#+end_src
